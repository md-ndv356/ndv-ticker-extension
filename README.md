# Natural Disaster Viewer (NDV) - Extension

Natural Disaster Viewer (NDV) - Extension では、緊急地震速報や気象情報をリアルタイムでティッカーに表示します。

【主な機能】

・通知音ですぐに通知
　緊急地震速報・竜巻注意情報・気象特別警報・津波情報・記録的短時間大雨情報・指定河川洪水予報（氾濫危険情報・氾濫発生情報） に対応

・VOICEVOX の音声による情報の読み上げ
　緊急地震速報・記録的短時間大雨情報・竜巻注意情報 に対応

・最大化
　表示部分をティッカーの画面のみに限定します。画面の端に置いておくことができます。最小化ではないかという意見は認めます。

・多言語対応
　地震情報・津波情報・記録的短時間大雨情報・特別警報報知には英語表示が存在します。

・音楽再生（おまけ）
　Web Audio API を使い、ループ範囲の指定をした滑らかなループ再生が可能です。音量も200%まで設定することができます。おまけ機能なのに未だに消していないのは、地味にこだわっているからです。緊急地震速報との連携などはありませんのでご了承ください。
